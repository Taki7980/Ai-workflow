# Shared Research Cache

Durable, verified discoveries shared by Agy CLI, Agy IDE, and Codex. Search before code traversal.

## Freshness

```yaml
verified_at: YYYY-MM-DD
head: <git-commit-hash>
```

These heads tag the entire cache snapshot. `brief.ps1` returns no research hits when the head differs. Refresh verified entries before updating the snapshot.

Store routes, symbols, call traces, invariants, proof, and known limits. Never store transcripts, raw command output, secrets, guesses, or facts obvious from source.
