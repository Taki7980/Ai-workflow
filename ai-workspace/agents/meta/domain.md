# Domain Docs

Reuse the existing Obsidian vault. Do not create duplicate `CONTEXT.md` or `docs/adr/` trees.

## Before exploring

1. Read `ai-workspace/Obsidian/Glossary.md` for shared language.
2. Read the relevant `Backend/index.md` or `Frontend/index.md`.
3. Follow only links relevant to the task.
4. Read matching files under `ai-workspace/Obsidian/Decisions/` when a decision may constrain the change.

## Rules

- Use glossary terms in plans, code, tests, issues, and reviews.
- Mark missing facts `TBD`; do not invent domain rules.
- Surface conflicts with existing decisions.
- Update domain documentation only when the task establishes reusable language or a durable decision.
